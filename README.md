# Web3CorePro

Tracks user authentication and authorization for Web3 applications using decentralized identity protocols and blockchain APIs.

Web3CorePro is built to be simple and practical, focusing on doing one thing well.

**Why Web3CorePro?**

- Tracks user authentication and authorization
- for Web3 applications using decentralized
- identity protocols and blockchain APIs

## Technology Stack

- python

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/Web3CorePro.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Runtime options can be set in the config file or overridden per call. The most commonly changed values are:
- **timeout**: how long operations may run before failing
- **retries**: how many times a failed operation is re-attempted
- **cache**: where temporary results are stored
